# 소리결

소리를 듣지 않아도 음악의 구성 요소와 분위기를 그림으로 느끼는 웹앱입니다. 해커톤 주제 '소리'를 위해 만들었습니다.

## 실행

```bash
npm install
npm run dev
```

배포할 때는 `npm run build`로 만든 `release/index.html` 단일 파일을 정적 호스팅에 올리면 됩니다. 서버는 필요 없습니다.

```bash
npm test
```

## 기능

- **음악 넣기**: 샘플 곡 4개, 파일 업로드, 음악 파일 링크, 유튜브 링크, 마이크, 유튜브 영상 링크(이 탭의 소리 공유)
- **스타일 9종**: 수묵화, 은하, 오로라, 궤도, 고양이 밴드, 사이매틱스, 네온 터널, 정원, 마블링
- **색 조합**: 기본, 숲, 보랏빛, 네온, 노을, 흑백 중에서 그림과 범례의 색을 한 번에 바꿉니다. 사용자 지정을 고르면 색상, 채도, 따뜻함을 직접 조절할 수 있습니다. 저장하는 영상에도 적용됩니다.
- **고양이 밴드**: 회색 고양이는 드럼 세트, 크림 고양이는 베이스 기타, 치즈 고양이는 마이크, 턱시도 고양이는 피아노를 맡는 밴드입니다. 담당 요소의 세기에 따라 각 고양이와 악기의 크기가 독립적으로 변하며, BPM에 맞춰 드럼 스틱·베이스 손·노래·피아노 손이 움직입니다. 고양이나 악기를 클릭하면 머리 위에 ❤️가 떠올랐다가 사라집니다. 확대·이동 상태에서도 클릭할 수 있으며 드래그는 하트를 만들지 않습니다. 소리 효과는 없습니다. 시각화 영역에 포커스를 둔 뒤 Enter로 네 고양이에게 차례로 하트를 보낼 수도 있습니다.
- **사이매틱스 클릭**: 클릭한 위치 주변 모래가 위로 튀고 흩어진 뒤 다시 무늬에 모입니다. 시각화 영역에 포커스한 뒤 Enter를 누르면 가운데 모래가 튑니다.
- **오로라 호수 클릭**: 호수를 클릭하면 그 위치에서 타원형 파문이 퍼지고 반사된 빛이 일렁이다가 사라집니다. 하늘 클릭은 무시하고, 시각화 영역의 Enter는 호수 가운데에 파문을 만듭니다. 확대·이동 후에도 클릭 위치를 따르며 드래그에는 파문이 생기지 않습니다.
- **정원 클릭**: 클릭한 꽃이 줄기에서 떨어져 사라진 뒤 같은 줄기 끝에서 다시 자라 피어납니다. 해바라기도 같은 방식이며, 빈 곳이나 줄기만 클릭하면 꽃을 떨어뜨리지 않습니다. Enter로 앞쪽 꽃을 하나 고를 수도 있습니다.
- **마블링 섞기**: 드래그 경로를 따라 기존 물감에 흐름을 더해 섞습니다. 새 물감이나 소리를 추가하지 않습니다. 휠로 확대하고, Shift+드래그로 화면을 이동합니다.
- **박자 반응**: 실시간 타격 감지와 BPM·박자 위치 추적을 함께 사용합니다. 궤도와 네온 터널은 감지 순간에 빠르게 반응하고, 신뢰도가 충분하면 추정한 박자로 회전·전진합니다. 밝기에는 별도의 번쩍임 제한을 적용합니다.
- **요소 집중**: 설명의 드럼·베이스·보컬·멜로디 버튼을 누르면 선택한 요소를 강조합니다. 같은 버튼을 다시 누르면 전체 보기로 돌아옵니다. 음악과 분석은 계속 유지됩니다.
- **시점 조절**: 은하·궤도는 드래그로 입체 회전, 네온 터널은 시선 이동이 됩니다. 나머지 6종은 휠로 확대한 뒤 드래그해 그림을 이동합니다(마블링은 Shift+드래그). 은하의 별·성운·충격파·혜성은 같은 3D 시점을 사용합니다. 휠 확대·축소와 더블클릭 초기화는 모든 스타일에서 됩니다. 스타일을 바꾸면 시점은 초기화되고 집중할 요소는 유지됩니다.
- **튜토리얼**: 네 악기를 하나씩 보여 준 뒤 집중, 분위기, 스타일, 색 조합, 시점, 재생, 번쩍임, 영상, 화면, 음악 넣기를 차례로 소개합니다. 첫 화면에서 시작하거나 샘플 곡 재생 중에 시작하면 전용 샘플 곡으로 그 악기의 소리만 들려줍니다. 내 파일, 유튜브, 마이크에서는 소리를 분리할 수 없어 그림만 강조합니다.
- **자막**: 곡을 재생한 뒤 메뉴의 자막 올리기로 SRT, VTT, LRC 파일을 올리면 재생 시간에 맞춰 표시합니다. 저장하는 영상에는 들어가지 않습니다.
- **진동**: 안드로이드 Chrome에서 샘플 곡을 재생할 때 드럼에 맞춰 휴대폰이 진동합니다. 메뉴의 버튼으로 끄고 켤 수 있습니다.
- **설명 창 크기**: 설명 창 왼쪽 아래 모서리를 끌면 창 전체가 같은 비율로 커지거나 작아집니다. 충분히 키우면 악기 설명이 항상 보이고, 두 번 누르면 처음 크기로 돌아옵니다.
- **모바일**: 폰 크기에서는 버튼을 키우고 메뉴를 나눠 배치하며, 설명 창은 숨긴 상태로 시작합니다.
- **소리 요소 구분**: 드럼, 베이스, 보컬, 멜로디마다 색과 도형이 다르고, 스타일마다 다른 그림 요소로 나타납니다.
- **분위기 표시**: 신나요, 평온해요, 슬퍼요, 강렬해요. 배경색, 움직임, 날씨가 함께 바뀝니다.
- **번쩍임 줄이기**: 꺼져 있어도 초당 3회 제한(WCAG 2.3.1)을 지키고, 켜면 빠른 밝기 변화를 부드러운 변화로 바꿉니다. 운영체제에서 '동작 줄이기'를 켜 두면 처음부터 켜집니다.
- **소리 없이 보기(파일·샘플)**: 분석이 볼륨 조절 앞단에서 이뤄져 앱의 소리를 꺼도 그림이 그대로 움직입니다. 유튜브는 플레이어를 음소거하면 캡처도 무음이 되어 그림이 멈출 수 있습니다.

단축키: `Space` 재생/일시정지, `←` `→` 5초 이동, `1`~`9` 스타일, `F` 전체 화면, `H` 설명 숨기기, `C` 색 조합 바꾸기

키보드 시점 조절: 시각화 영역에 Tab으로 이동한 뒤 `Shift`+방향키로 이동·회전, `+`/`-`로 확대·축소, `Home`으로 초기화합니다. 요소 집중 버튼은 Tab과 Enter/Space로 조작합니다.

## 영상 저장·공유

하단 **영상 만들기**에서 15초·30초, 세로 9:16·정사각형·현재 화면을 선택하고 **소리 포함 녹화 시작**을 누릅니다. 현재 위치부터 실시간으로 녹화하며 그림과 음악을 함께 저장합니다. 전체 그림을 유지하므로 화면 비율에 따라 여백이 생깁니다. 메뉴·설명·유튜브 플레이어는 저장하지 않습니다.

파일·샘플은 앱 볼륨이 적용된 소리를, 유튜브는 이미 공유 중인 탭 오디오를 사용합니다. 유튜브 음소거·광고 등 탭에서 들리는 소리도 그대로 반영됩니다. 녹화 중 미리보기 등 다른 소리를 같은 탭에서 재생하지 마세요. 캡처 오디오는 스피커로 다시 출력하지 않습니다.

길이에 도달하거나 음악이 일시정지·종료되거나 탭이 백그라운드로 바뀌면 녹화를 마치고 미리보기를 보여 줍니다. **녹화 마치기**로 짧게 끝낼 수도 있습니다. 미리보기를 재생하면 원래 음악은 일시정지합니다. 다른 곡으로 전환하거나 연결을 종료하면 진행 중인 녹화와 미리보기를 정리합니다. 영상은 브라우저 안에서 만들어지며 서버에 업로드하지 않습니다.

지원 브라우저에서는 MP4, 그 외에는 WebM으로 다운로드합니다. WebM은 인스타그램 업로드 전 MP4 변환이 필요할 수 있습니다. 다운로드한 파일을 휴대폰으로 옮겨 릴스·스토리 등에 직접 올리는 방식이며 인스타그램 자동 게시는 지원하지 않습니다. 녹화 중에는 이 탭을 열어 두고, 저장 후 미리보기로 영상과 소리를 확인하세요.

## 분석·입력의 한계

- **요소 분리는 추정입니다.** 학습된 음원 분리 모델이 아니라 실시간 신호 처리로 판단합니다(하모닉/퍼커시브 분리, 스테레오 위치, 음높이 흔들림). 16분음표로 몰아치는 베이스는 드럼으로 오인하기 쉽고, 혼자 연주하는 가운데 정위 악기는 보컬이나 멜로디로 갈릴 수 있습니다.
- **분위기는 조성, 활동량, 밝기로 추정합니다.** 곡의 앞 몇 초 동안은 '읽는 중'으로 표시되고, 새 분위기가 3초 이상 이어져야 표시가 바뀝니다. 클래식 위주의 공개 음원 15곡으로 잰 일치율은 12곡이며, 곡 수가 적어 대략적인 값입니다.
- **마이크는 주변 소리에도 반응합니다.** 대개 모노라서 보컬과 멜로디 구분이 약해지고, 재생 위치 조절은 없습니다. 소리는 분석에만 쓰고 저장하거나 보내지 않습니다.
- **BPM은 60~200 범위에서 추정합니다.** 처음에는 여러 타격을 모아야 하며, 박자가 불규칙하거나 세분된 곡은 반·배속으로 추정할 수 있습니다. 신뢰도가 낮으면 실제 감지한 타격에 반응합니다.
- **링크는 유튜브 영상과 음악 파일 직링크를 지원합니다.** 유튜브는 앱 안의 플레이어를 재생하고 사용자가 허용한 이 탭의 소리를 분석합니다. 스포티파이 등 다른 스트리밍 서비스는 지원하지 않으며, 파일 링크는 해당 서버가 CORS를 허용해야 합니다.
- 로그인, 결과 저장은 MVP에서 제외했습니다. 업로드한 파일은 브라우저 안에서만 쓰이고 저장되지 않습니다.

## 구조

- `src/audio/analyzer.ts`: 스펙트럼에서 요소, 음높이, 분위기를 뽑아내는 핵심. 브라우저 없이 테스트할 수 있습니다.
- `src/audio/flash.ts`: 밝기 변화를 제한하는 번쩍임 가드. 시각화는 빛에 `pulse`만 사용합니다.
- `src/audio/samples.ts`: 브라우저에서 합성하는 샘플 곡(저작권 문제 없음)과 정답 일정.
- `src/audio/youtube.ts`: 공유 요청과 IFrame Player API 로드·재생·오류·해제. 캡처 스트림은 `engine.ts`의 분석 전용 입력으로만 연결합니다.
- `src/visuals/`: 스타일별 렌더러.
- `tests/accuracy.test.ts`: 샘플 곡 전체를 오프라인으로 분석해 정답 일정과 비교합니다.

`design.md`(Toss TDS)를 따릅니다. 한 가지는 의도적으로 다릅니다. 채운 버튼의 배경을 `#3182f6` 대신 `#1b64da`로 썼습니다. 흰 글자와의 대비가 3.71:1에서 5.41:1로 올라가 WCAG AA를 통과합니다. `src/styles.css`의 `--action`을 바꾸면 원래 토큰으로 돌아갑니다.

## 유튜브 연결

PC의 Chrome 또는 Edge에서 `https://` 배포본이나 `npm run dev`의 localhost 주소를 엽니다. 유튜브 링크를 입력하고 `열기`를 누른 뒤, 공유 창에서 **소리결이 열린 이 탭**과 **탭 오디오 공유**를 선택합니다. 자동 재생이 막히면 화면 왼쪽의 유튜브 플레이어에서 재생 버튼을 누릅니다. 플레이어는 항상 보이게 유지됩니다.

- 음원을 다운로드하거나 저장하지 않으며 서버·프록시는 사용하지 않습니다. 영상 광고의 소리도 분석됩니다.
- Firefox·Safari에서는 미지원 안내를 표시합니다. HTML 파일을 더블클릭한 `file://` 환경은 유튜브 연결 대신 https/localhost 실행을 안내합니다.
- 공유 옵션은 브라우저에 보내는 선호값이므로 특정 탭을 강제로 선택할 수 없습니다. 반드시 이 탭을 직접 선택해야 합니다. 화면·창 공유를 선택하면 다시 안내합니다.
- 유튜브의 소리 크기는 유튜브 플레이어에서 조절합니다. 공유 중에는 앱의 소리 슬라이더와 파일용 음소거 안내를 숨깁니다.
- 캡처가 모노이면 좌우 차이를 사용하는 보컬·멜로디 구분이 약해질 수 있습니다. 분석기는 수정하지 않았습니다.
- 실제 캡처 채널 수는 수동 확인 전이라 미측정입니다. 연결 후 `#youtube-panel`의 `data-audio-channels`에 알려진 값(1=모노, 2=스테레오) 또는 `unknown`을 기록합니다.
- 비디오를 중지해도 오디오가 유지되는지 수동 확인 전이므로 연결 중에는 비디오 트랙을 유지합니다. 화면 영상은 읽거나 표시·저장하지 않고, 종료할 때 모든 트랙을 중지합니다.
- 공개 서비스로 운영하기 전에 유튜브 약관을 다시 확인해야 합니다. 플레이어를 가리거나 숨기지 않습니다.

옵션은 [MDN getDisplayMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia), [Chrome 공유 제어 문서](https://developer.chrome.com/docs/web-platform/screen-sharing-controls)를 확인해 작업 지시서 기준값 그대로 사용했습니다. [YouTube API 문서](https://developers.google.com/youtube/iframe_api_reference)에 추가된 오류 153(사이트 식별 정보 누락)도 안내하며, iframe에 `strict-origin-when-cross-origin` referrer 정책을 적용합니다.

### 실제 공유 수동 확인 — 아직 미확인

자동 테스트의 모의 API 검사는 아래 항목의 통과를 뜻하지 않습니다. Chrome에서 사람이 확인해야 합니다.

- [ ] 유튜브 URL 입력 → 이 탭·탭 오디오 공유 허용 → 소리에 맞춰 시각화
